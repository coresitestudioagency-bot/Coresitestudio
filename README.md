## What this is

A static agency homepage plus an explore / prompt vault.

- **Home** — studio intro, journal, contact, and Prompt nav
- **Explore** — template cards with live preview and full AI build prompts
- **Bloom & Petal** — flagship florist template (studio original)

The idea: **the prompt is the product.** Open a card, run the preview, then copy the prompt that generated the site.

## Features

- Sketch UI: paper canvas, handwriting type, wobbly borders
- Mobile: two template / journal cards side by side
- Prompt navbar item jumps straight to Explore
- Digital Store shows an under-construction notice until launch
- Web and video prompt tabs in the vault
- First-visit preloader on the home page

## Local preview (studio only)

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 and http://localhost:8000/explore.html

This is for running the studio site locally. It is not permission to clone, modify, or ship a copy.

## 🚀 How to Run the Website

### Option 1: Development Mode
```bash
npm run dev
```
Then open: http://localhost:3000

### Option 2: Production Build
```bash
npm run build
```
The built files will be in the `dist/` folder.

### Option 3: Preview Production Build
```bash
npm run preview
```
